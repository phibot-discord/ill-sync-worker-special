# phi-specials

The Phigros items `phi-unpackd` leaves out because only the Chapter 9 passcode or the game's code
gives them. The daemon stays generic, so a new game version flows through it with no edits. This tool is run by
hand when one of these items changes. It reuses the daemon's crate for every reader and for uploads, so its files
are made and published exactly as the daemon's are.
